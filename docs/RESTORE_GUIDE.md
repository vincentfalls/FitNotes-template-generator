# How to Restore Workout Templates in FitNotes (Android) & FitNotes 2 (iOS)

This guide walks you through importing the `.fitnotes` files generated by the FitNotes Template Generator into your phone.

---

## 🍏 iOS (FitNotes 2)

### Method 1: Direct File Import (Recommended)
1. Download your generated `.fitnotes` file (e.g. `ppl_6day.fitnotes` or your updated backup) on your iPhone.
2. Open the **Files** app on iOS.
3. Locate the `.fitnotes` file in your **Downloads** folder.
4. Tap the file, then tap the **Share** icon (square with arrow pointing up).
5. Select **FitNotes 2** from the app list.
6. FitNotes 2 will open and ask to restore/import the database. Confirm the restore.

### Method 2: iCloud Backup & Restore
1. Save the `.fitnotes` file into your **iCloud Drive > FitNotes 2** folder.
2. Open **FitNotes 2**.
3. Tap **Settings** (gear icon) > **Backup & Export** > **Restore**.
4. Select the `.fitnotes` file from the list to load your new routines!

---

## 🤖 Android (FitNotes)

### Method 1: Local Backup Folder Restore
1. Download the generated `.fitnotes` file on your Android device.
2. Using any file manager app, move the file into the FitNotes backup folder:
   - Path: `Internal Storage/FitNotes/Backup/` (or `Downloads/`)
3. Open **FitNotes**.
4. Tap the **Menu (three dots / drawer)** > **Settings** > **Backup/Restore**.
5. Tap **Restore Backup**.
6. Select your `.fitnotes` file and confirm the restore.

### Method 2: Google Drive / Cloud Restore
1. Upload your `.fitnotes` file to your Google Drive or Dropbox.
2. In **FitNotes** settings, select **Google Drive** / **Dropbox** under Backup/Restore.
3. Choose the backup file to restore.

---

> [!TIP]
> **Using the Merger Feature**: If you already have workout history logged in FitNotes, always use the **"Merge into Existing Backup"** feature in the Template Generator. This ensures all your personal records, historical weights, and logged workouts are 100% preserved while adding the new routines!
